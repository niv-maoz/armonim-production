הכתובת מופיעה **פעם אחת בלבד** בקובץ, ב-`href` של הכפתור. להחלפת הטופס
בשנה הבאה — לשנות שם בלבד.

**בדיקה שחובה לעשות לפני ההפצה:** לפתוח את הטופס בדפדפן פרטי (גלישה בסתר)
עם חשבון גוגל **שאינו** שלך ולוודא שהוא נפתח ומאפשר העלאה. שאלת העלאת קובץ
בטופס גוגל תמיד דורשת התחברות — אבל אם הטופס מוגבל לדומיין של בית הספר,
תלמיד שמחובר בטלפון לחשבון פרטי ייחסם. ההגדרה נמצאת ב:
**הגדרות ← תגובות ← הגבל למשתמשים בארגון שלך**.

## שלב 1 — להעלות ל-GitHub Pages

1. לפתוח חשבון חינמי ב-[github.com](https://github.com).
2. **New repository** ← שם: `armonim-production` ← לסמן **Public** ← Create.
   (חייב Public. מאגר פרטי לא מקבל אירוח חינמי.)
3. **Add file ← Upload files** ← לגרור לשם את `index.html`,
   ואת התיקיות `images` ו-`fonts` במלואן ← **Commit changes**.
4. **Settings ← Pages** ← תחת Source לבחור **Deploy from a branch**,
   ענף `main`, תיקייה `/ (root)` ← **Save**.
5. להמתין דקה. הכתובת תופיע שם:
   `https://<שם-המשתמש>.github.io/armonim-production/`

הכתובת הזו קבועה. אם תשנה את תוכן המשימה בשנה הבאה, תעלה `index.html` מעודכן
לאותו מאגר — הכתובת לא זזה, וקוד ה-QR המודפס ממשיך לעבוד.

## שלב 2 — קוד QR

אחרי שיש כתובת חיה, אפשר לייצר קוד QR להדפסה. אין ספריית QR מותקנת כרגע במחשב;
התקנה חד-פעמית:

```bash
pip install segno
```

ואז אפשר לייצר את הקוד מהכתובת. כדאי להדפיס אותו בגודל של 5 ס"מ לפחות,
ולבדוק סריקה ממרחק של חצי מטר לפני שתולים בכיתה.
