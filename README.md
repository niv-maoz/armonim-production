## ✅ טופס ההגשה — כבר משולב

כפתור "העלאת הסרטון" בעמוד מחובר לטופס:

```
https://docs.google.com/forms/d/e/1FAIpQLSexsDktlXfq3W2JZN6AMetVoq6DtLDMKdflGtRDeqwUaWDRNA/viewform
```

הכתובת מופיעה **פעם אחת בלבד** בקובץ, ב-`href` של הכפתור. להחלפת הטופס
בשנה הבאה — לשנות שם בלבד.

**בדיקה שחובה לעשות לפני ההפצה:** לפתוח את הטופס בדפדפן פרטי (גלישה בסתר)
עם חשבון גוגל **שאינו** שלך ולוודא שהוא נפתח ומאפשר העלאה. שאלת העלאת קובץ
בטופס גוגל תמיד דורשת התחברות — אבל אם הטופס מוגבל לדומיין של בית הספר,
תלמיד שמחובר בטלפון לחשבון פרטי ייחסם. ההגדרה נמצאת ב:
**הגדרות ← תגובות ← הגבל למשתמשים בארגון שלך**.

## איך לעדכן את העמוד בעתיד

המאגר כבר מחובר. אחרי שינוי ב-`index.html` (או בתמונות), מריצים בתיקיית הפרויקט:

```bash
git add . && git commit -m "עדכון תוכן המשימה" && git push
```

תוך דקה השינוי באוויר. **הכתובת לא זזה לעולם**, אז קוד ה-QR המודפס
ממשיך לעבוד גם בשנים הבאות.

---

## קוד ה-QR

נמצא בתיקיית `qr/`. נוצר ברמת תיקון שגיאות H — סובל עד כ-30% נזק,
מה שחשוב לדף שתלוי על קיר כיתה ונשחק.

להדפסה: **5 ס"מ לפחות**. לבדוק סריקה ממרחק של חצי מטר לפני שתולים.

## מה עוד כדאי לבדוק לפני ההפצה

- לפתוח את הכתובת בטלפון אחד לפחות שאינו שלך.
- ללחוץ על כפתור ההגשה ולוודא שהטופס נפתח ומקבל קובץ.
- לוודא שהתאריך בעמוד (8.10.2026) הוא אכן המועד הנכון.

## עדכון תוכן בשנה הבאה

כל הטקסט יושב ב-`index.html` בעברית רגילה, בלי מנגנון תבניות.
להחליף חפצים: להחליף קבצים בתיקייה `images` ולעדכן את הכיתוב המתאים.
לפני שינוי מהותי כדאי לקרוא את `PRODUCT.md` — הוא מתעד למי העמוד מיועד
ואילו אילוצים אסור לשבור.
